## What I do

I study how the ocean warms and circulates — **marine heatwaves, ocean circulation and air–sea interaction** — using satellite and reanalysis data, regional models and machine learning.

The rest of my time goes into turning research work into tools that are easy to reuse:

- **Websites** — fast, static-first sites (Astro, Nuxt) for projects, docs and portfolios.
- **Automation** — Python and MATLAB scripts, scheduled jobs and Cloudflare Workers.
- **Templates** — LaTeX/Beamer and PowerPoint slides, posters and project pages.
- **Self-hosted services** — Docker tools and a personal cloud I can inspect and extend.

Everything else lives on my site — **[jswang.chum-bucket.site](https://jswang.chum-bucket.site/)** ([中文](https://jswang.chum-bucket.site/zh/)): portfolio, projects, slides and templates.
