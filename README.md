## What I build

I like the point where a one-off page becomes a reusable template: static sites that stay fast, scripts that remove a repetitive task, and decks that make a talk easier to follow.

- **Static-first web** — Astro and Nuxt sites with little JavaScript and a low maintenance cost.
- **Small automation** — Python pipelines, scheduled jobs and Cloudflare Workers.
- **Self-hosted utilities** — Docker services and personal cloud tools I can inspect and extend.
- **Templates & slides** — LaTeX, Beamer, PowerPoint, Typst and web layouts.
